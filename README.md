# lvl4-w6

This is an app that allows a user to add new items to a list for remembering items for a trip, toggle if it has been packed or not, update/edit the items, and delete the items from one page that renders the list live. 
This was refactored to use ResourceContext to help manage state props and API fetching while using multiple components, making it easier to add new components to the app later as it avoids prop drilling.  

Backend: 
cd backend 
pip install -r requirements.txt 
python app.py

Frontend: 
cd frontend 
npm run dev

CREATE TABLE gear (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  item_name TEXT NOT NULL,
  category TEXT DEFAULT 'General',
  quantity INT DEFAULT 1,
  is_packed BOOLEAN DEFAULT FALSE,
  notes TEXT DEFAULT ''
);
